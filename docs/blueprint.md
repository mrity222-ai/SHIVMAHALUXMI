# **App Name**: LuxeSolar

## Core Features:

- AI Solar Feasibility Concierge: An AI-powered tool that analyzes user inputs regarding roof size and local sunlight data to recommend specific installation configurations.
- Dynamic Motion Portfolio: An interactive, animated gallery displaying before and after solar project results with scroll-triggered GSAP visual effects.
- Secure Lead Inquiry Vault: A robust lead generation system that captures and stores customer contact information and subsidy requests in the Firestore database.
- Subsidy Logic Wizard: A multi-step interactive UI form that helps users calculate potential government subsidy benefits based on their residential or commercial profile.
- Premium Editorial Hub: An SEO-optimized blog structure with fast loading speeds, built using Next.js for high search engine ranking performance.
- Interactive Contact Bridge: Direct communication layer including a floating WhatsApp integration, real-time Google Maps display, and validated contact forms.
- Animated Impact Dashboard: Real-time visual counters that demonstrate environmental impact stats and completed energy project volumes using Framer Motion.

## Style Guidelines:

- Primary color: A high-tech Emerald Green (#10B981) to represent clean energy and sustainable premium quality.
- Background color: A deeply sophisticated Charcoal Emerald (#061410), providing an ultra-dark backdrop for modern high-contrast design.
- Accent color: A vibrant Electric Lime (#86EFAC) to create energetic contrast for call-to-action buttons and visual highlights.
- Headline font: 'Space Grotesk' (sans-serif) for a modern, tech-focused, and scientific industrial feel. Body font: 'Inter' (sans-serif) for clean readability across multi-page layouts.
- Corporate multi-page layout utilizing glassmorphism panels, excessive negative space, and a floating persistent navigation bar.
- Cinema-style entrance transitions with GSAP and silky smooth inertia scrolling with Framer Motion.
- Thick-line modern icons with slight green-glow gradients to match the brand’s technical expertise.
